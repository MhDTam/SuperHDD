# SuperHDD screenshots

Captured from the running **0.1.1** application frontend using Playwright and
Chrome at `http://127.0.0.1:1420/?demo=1`. This is the same React interface used
by the Tauri desktop host.

All screenshots use the built-in **design preview**. Disk models, drive letters,
capacities, and chart values are example data, not a snapshot of the developer's
machine or benchmark results. The preview banner remains visible in each image.
The images were captured directly from the rendered UI without compositing or
changing their contents.

The viewport is 1440 × 1000, except the performance view (1440 × 1200).
